# Zooly Game
Projeto de desenvolvimento do Zooly Game, uma aplicação gamificada voltada ao apoio da aprendizagem e ao acompanhamento do progresso dos alunos.

## Objetivo do projeto

Desenvolver uma aplicação que ofereça aos alunos uma experiência gamificada de aprendizagem, permitindo a realização de atividades e o acompanhamento do progresso.

## Gestão Ágil

O planejamento e acompanhamento do projeto serão realizados utilizando GitHub Issues e GitHub Projects, com organização por Épicos, Histórias de Usuário, prioridades, estimativas e Sprint.

## Tecnologias

- Front-end: React
- Back-end: Node.js / Express
- Banco de dados: MySQL
