# Zooly Game — Gestão Ágil

## Sobre o Projeto

O Zooly Game é um projeto desenvolvido para apoiar atividades de leitura e fala de forma interativa e gamificada.

## Gestão Ágil

O projeto utiliza o GitHub Projects para organização do Product Backlog, planejamento das Sprints e acompanhamento das atividades.

## Papéis da Squad

### Product Owner (PO)
Responsável por representar as necessidades do produto, definir prioridades e organizar o Product Backlog.

### Product Manager (PM)
Responsável pelo planejamento, acompanhamento e organização das entregas do projeto.

### Desenvolvedores
Responsáveis pela implementação das funcionalidades do sistema, incluindo desenvolvimento, banco de dados, interface e integrações.

## Product Backlog

O backlog é organizado em Épicos e Histórias de Usuário.

Foram definidos dois Épicos:

- [Épico] Experiência e Progresso do Aluno
- [Épico] Atividades de Leitura e Feedback de Fala

Cada Épico foi dividido em Histórias de Usuário menores e testáveis.

## Estimativas

### T-Shirt Sizing

Os Épicos são estimados utilizando:

- PP — Muito pequeno
- P — Pequeno
- M — Médio
- G — Grande
- GG — Muito grande

### Story Points

As Histórias de Usuário utilizam a escala Fibonacci:

- 1
- 2
- 3
- 5
- 8

## Definition of Ready (DoR)

Uma história está pronta para entrar em desenvolvimento quando:

- [ ] Possui descrição no formato Como / Desejo / Para.
- [ ] Possui critérios de aceitação definidos.
- [ ] Possui prioridade definida.
- [ ] Possui Story Points definidos.
- [ ] Possui responsável definido.
- [ ] Possui Parent/Epico definido.
- [ ] Dependências foram identificadas.
- [ ] A história é pequena o suficiente para ser desenvolvida dentro da Sprint.

## Definition of Done (DoD)

Uma história é considerada concluída quando:

- [ ] Funcionalidade implementada.
- [ ] Validações realizadas.
- [ ] API funcionando quando necessária.
- [ ] Interface funcionando.
- [ ] Dados persistidos corretamente quando necessários.
- [ ] Testes realizados.
- [ ] Interface responsiva quando aplicável.
- [ ] Código revisado.
